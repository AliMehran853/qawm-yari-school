# مکتب قوم یاری ورس بامیان

سامانه مدیریت و وب‌سایت رسمی مکتب قوم یاری — ولسوالی ورس، ولایت بامیان.

## ویژگی‌ها

- 📱 **PWA** — قابل نصب روی موبایل، کار آفلاین
- 🌐 **سایت عمومی** — معرفی مکتب، کادر، صنوف، اخبار، گالری، کتابخانه
- 🔐 **پنل مدیریت** — مدیریت کامل مکتب
- 📊 **مدیریت دانش‌آموزان** — ثبت، ویرایش، جستجو
- 📝 **ورود نمرات** — دور اول (۴۰) و نهایی (۶۰)
- 📄 **کارنامه** — با محاسبه خودکار معدل و رتبه
- ✅ **حضور و غیاب** — روزانه
- 📢 **اعلانات** — با ارسال در واتساپ
- 💾 **پشتیبان‌گیری** — خروجی و ورود JSON

## تکنولوژی

- **فرانت‌اند:** React 19 + Vite + Tailwind CSS 4
- **بک‌اند:** Supabase (Postgres + Auth + RLS)
- **State:** Zustand + TanStack Query
- **PWA:** vite-plugin-pwa + Workbox
- **میزبانی:** Vercel (فرانت‌اند) + Supabase (بک‌اند)

## نصب و راه‌اندازی

```bash

# ساخت .env با مقادیر Supabase

# ویرایش .env و پر کردن مقادیر
